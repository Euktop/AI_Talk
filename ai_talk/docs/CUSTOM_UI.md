# CUSTOM UI — спецификация

Замена старого файлового CUSTOM-режима (`ai_talk/infrastructure/custom_client.py`)
на локальный web-UI. Старый удаляется.

## Идея

Скрипт на базе `AITalk` работает как обычно. Когда он вызывает
`ai.ask_ai(...)` в режиме `ModelRole.CUSTOM`, запрос ставится в локальную
очередь, открывается браузер, пользователь отвечает из UI. Скрипт
продолжает, когда ответ получен.

Запросы можно отвечать в любом порядке. Несколько запросов могут ждать
одновременно.

## Один экземпляр

- Сервер по умолчанию: `127.0.0.1:8765`.
- Занятый порт → второй экземпляр не стартует, клиент подключается
  к уже запущенному.
- Lock-файл не используется: проверка через сам факт bind.

## Lifecycle

1. Первый `ask_ai()` в CUSTOM-режиме: если сервер не запущен — поднимаем
   subprocess `python -m ai_talk.custom_ui`, ждём `/health`, открываем
   браузер.
2. Клиент регистрируется: `POST /api/clients/register`.
3. При создании запроса: `POST /api/requests` → `id`.
4. Ждём ответа: `GET /api/requests/<id>/wait` (long-poll, timeout 1 час).
5. По завершении скрипта: `atexit` → `POST /api/clients/unregister`.
6. Сервер: когда `clients == 0` и `requests == 0` — ждёт 5 секунд → выход.

Если был хотя бы один клиент и после его ухода очередь пуста — сервер
выходит. Если очередь не пуста — ждёт, пока разберут.

## UI (Фаза 3 готова, 4–6 в работе)

Один экран, светлая тема:

```
┌────────────────────────────────────────────────────────────┐
│ AI_Talk                                       [N активных] │
├────────────────────────────────────────────────────────────┤
│ [?] Это тестовый текс с ашипкой…    [📋]  [📥]            │
│ [?] Переведи следующий текст на…    [📋]  [📥]            │
└────────────────────────────────────────────────────────────┘
```

- **Клик по тексту** = копировать полный текст запроса.
- **Клик по `[📋]`** = то же. Успех — зелёный flash 1.5 с. Пустой
  буфер — красный flash.
- **Клик по `[?]`** = модалка с полным текстом + «Скачать .txt» +
  «Копировать всё».
- **Клик по `[📥]`** = вставить из буфера как ответ.
  - Непустой буфер → сохранить, удалить запрос, перейти к следующему.
  - Пусто → красный flash, ничего не сохраняется.
  - **Никаких текстовых сообщений — только цвет.**
- Список автообновляется каждые 2 секунды.
- Long-poll для ожидания ответа.

## Горячие клавиши (Фаза 6)

- **`Ctrl+Shift+C`** — команда A: копировать текущий запрос, перейти
  к следующему. На последней строке копируется **пустая строка**
  (сигнал «конец списка»), выделение уходит на первую.
- **`Ctrl+Shift+V`** — команда B: вставить из буфера в текущий,
  удалить, перейти к следующему.
- `Esc` — закрыть модалку.
- `Ctrl+Enter` — подтвердить вставку в модалке.

Специфицированы сейчас, реализуются последними.

## HTTP API

| Метод | Путь | Смысл |
|---|---|---|
| GET | `/health` | `{"status":"ok"}` |
| POST | `/api/clients/register` | `{client_id}` → `{ok}` |
| POST | `/api/clients/unregister` | `{client_id}` → `{ok}` |
| POST | `/api/requests` | `{system_prompt, user_prompt}` → `{id}` |
| GET | `/api/requests` | `[{id, preview, created_at, has_answer}, …]` |
| GET | `/api/requests/<id>/raw` | `text/plain` |
| GET | `/api/requests/<id>/wait` | long-poll |
| POST | `/api/requests/<id>/answer` | `{answer}`; пусто → 400 |
| POST | `/api/requests/<id>/ack` | удалить запрос (клиент подтвердил получение) |

`GET /api/requests` возвращает только **неотвеченные** запросы
(`pending_only=True`). Отвеченный запрос скрывается из списка UI, но
остаётся в БД до `/ack` от клиента — иначе `wait` не увидел бы ответ.

## Хранилище

SQLite `~/.ai_talk/custom_ui.db`. Путь переопределяется
`--db`. Схема: таблицы `requests` и `clients`, см. `storage.py`.

## Зависимости

- `[project.optional-dependencies].ui = ["flask>=3"]`.
- Не в `dependencies`: пользователи, которые не пользуются CUSTOM,
  не тянут flask.

## Совместимость

- `ModelRole.CUSTOM` — имя сохраняется, поведение меняется.
- `AITalk.ask_ai / ask_ai_structured / get_text` — сигнатуры те же.
- `custom_dir` (параметр `AITalk.__init__`) — принимается для совместимости,
  игнорируется. Реальная папка данных: `~/.ai_talk/`.
- Старые файлы `запросы_к_ии/*.md`, папка `архив/`, префикс `done_`,
  маркер `## 🟢 ВАШ ОТВЕТ` — больше не используются. Скрипты, которые
  полагались на файловую очередь, должны перейти на новый режим.

Это поведенческий breaking change → bump `2.2.0` → `2.3.0`.
