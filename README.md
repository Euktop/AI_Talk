# 🧠 AI_Talk

**AI_Talk** — это легковесная Python-библиотека для безопасного взаимодействия с локальными LLM (Ollama). 
Главная особенность — **универсальный ввод**: библиотека сама определяет, передали вы ей путь к файлу или обычный текст, и предоставляет простые интерфейсы для работы с данными.

## 🚀 Возможности
1. **Умный парсинг ввода**: Автоматически отличает путь к `.md` / `.txt` файлу от обычной строки.
2. **Интерфейс для ИИ (`ask_ai`)**: Читает данные и отправляет их в локальную нейросеть.
3. **Интерфейс для кода (`get_text`)**: Читает данные и отдает их в ваш Python-скрипт.
4. **Fail-Safe**: Автоматическая проверка подключения к Ollama при старте.

## 📦 Установка

1. Убедитесь, что у вас установлена и запущена [Ollama](https://ollama.com/).
2. Скачайте модель (например, `ollama run qwen2.5:3b`).
3. Установите библиотеку из исходников:
   ```bash
   cd D:\repos\AI_Talk
   pip install -e .
   ```

## 💻 Примеры использования

### Сценарий 1: Передача файла в ИИ (Анализ заметки)
```python
from ai_talk import AITalk

ai = AITalk(model="qwen2.5:3b")
response = ai.ask_ai(
    source="D:\\My_notes\\00 Входящие\\мысли.md",
    system_prompt="Ты редактор. Исправь ошибки и верни JSON."
)
print(response)
```

### Сценарий 2: Получение текста из файла в свой скрипт
```python
from ai_talk import AITalk

ai = AITalk()
content = ai.get_text("D:\\My_notes\\00 Входящие\\мысли.md")
print(f"Длина текста: {len(content)} символов")
```
